# P51 运行与 Android 安装说明

本轮是原有 Keep 家庭 PWA 的增量音频改造，只供家庭私有使用，不发布第三方音频到公网。不需要 APK、账号或密钥。

## 已准备的本地版本

- React / React Router / Vite 沿用，现有错误边界、提示、页面外壳与 Range 能力复用；旧视频实现保留为 `src/LegacyVideoApp.tsx`，不作为默认产品入口。
- 真实资源：项目根目录 `兴趣测试`，30 门、1,905 文件、8,850,730,200 字节；20 个文件为大写 `.MP3`，均已识别。
- 扫描程序仅只读原音频，生成 `catalog/audio-index.json`；公开 API 只有课程、分集及不透明 URL，不暴露磁盘路径。
- 私有索引、原音频及完整扫描清单已在 `.gitignore` 排除。交付没有包含示范音频或虚构分集。
- 已使用本地缓存优先安装依赖；i18next 缓存缺失后使用 npmmirror，新增 i18next 25.6.0 / react-i18next 16.2.0（MIT），锁文件保留完整性校验；没有升级原有 React/Vite 技术栈。

## 本机浏览

项目目录内：

```sh
pnpm install --offline --frozen-lockfile
pnpm build
pnpm serve
```

默认 [电脑预览](http://127.0.0.1:8792/)。先检查端口；若被占用，不关闭其他服务，改用 `APP_PORT=其他空闲端口 pnpm serve`。`HOST` 默认 `127.0.0.1`，不暴露到公网。

需要重扫音频时运行 `pnpm audio:scan`，可用 `AUDIO_ROOT` 指定另一个实际音频根目录。文件层级仍须与清单的等级/学科/课程目录对应。缺失或损坏时脚本仍生成报告与可用目录，但以退出码 2 提醒；当前 4 份损坏源文件属于此情况，不能把退出码 2 写作全量资源通过。

开发模式可在另一个终端启动 `pnpm dev`（API 指向 8792；改端口时同步设 `API_PROXY_TARGET`）。正式离线验证使用 `pnpm build` 后的版本；Vite 开发模式不注册正式 SW。

## 已锁定手机的 USB 安全预览

保持 Redmi Note 11T Pro+ 的 USB 调试授权，执行：

```sh
node scripts/android-preview.mjs
```

脚本读取跨项目设备锁，逐次 status / resolve 后指定目标，不会自动换手机；检查端口并自动选取空闲端口，启动仅本任务前台运行的服务，通过 USB reverse 打开 Android Chrome 中的 `http://localhost:实际端口/`。终端输出准确链接。此 localhost 是安全上下文，可使用 Service Worker、Cache API 和安装提示。

不自动播放、不动系统音量。Ctrl+C 会停止本脚本创建的服务并移除它创建的 USB 转发，不创建开机项、登录项或自动重启服务。

默认锁定脚本路径按当前用户主目录计算；其他系统/智能体可通过 `ANDROID_DEVICE_LOCK_SCRIPT` 和 `PYTHON` 配置已安装的同一 Skill 脚本及 Python 命令。ADB 必须在 PATH 中。

端口变更会形成另一个浏览器来源；安装入口、缓存与记录按来源隔离。已安装小屋应继续使用安装时的相同主机名与端口，避免误以为旧缓存或记录丢失。当前真机安装确认来源为 `http://localhost:8792/`。

## 手机安装与离线

1. 首次连接服务，在 Android Chrome 打开小屋；设置页点击“安装小屋”，或使用 Chrome 的安装入口。
2. 打开课程，下载单集或整课；看到“已离线”才表示完整文件已提交。进度不足 100%、失败或暂停均不算下载完成。
3. 离线可保留首页、目录和已下载分集。未下载音频需要重新连接家庭服务。浏览器清除网站数据/系统回收空间可能删除缓存，不能承诺永久保存。
4. 删除缓存只删除设备副本，保留历史；不删除 Mac 上的原文件。整课下载暂停后保留已完成分集，再次下载会跳过已完成项并重试未完成项。
5. USB 断开后，如果课程已完整缓存，可在同一安装来源离线使用；要下载新课程，需重新连接服务。普通家庭局域网 HTTP 地址可以浏览，但不是完整安装/离线的安全上下文；长期无线使用需单独配置私有 HTTPS，并明确授权常驻服务，当前没有擅自创建。
