# 妹妹的听书小屋

把家里已有的听书课程，变成妹妹手机上的一座私人听书小屋：按学科和难度找课、逐集点播、睡前定时关闭、没网也能继续听。不用装 App、不用登录、音频永远不出家门。

## 这是什么

家里给孩子买了不少听书课程，文件躺在硬盘里，孩子想听一次得先经过电脑。这个项目把本地音频文件夹变成一个能在手机上安装、能离线收听的网页小屋：家里电脑当片库服务器，妹妹用她的手机打开、下载、断网也能听。适合任何「音频资料在本地、想让家里人随时随地听」的家庭。

## 核心功能

- **学科 × 难度书库**：左侧 7 个学科（文学、历史、科学科普、艺术音乐、地理博物、侦探推理、心理成长）、顶部 L1–L5 难度页签，加搜索框，几秒定位一门课；
- **真实分集与收听记录**：每门课按文件名自然序整理出分集列表，听过多少、听到哪一集，进度条直接可见，换页面不丢进度；
- **完整播放器**：倍速（0.75×–2×）、顺序/单集/列表循环、睡眠定时（15/30/60 分钟或本集结束），锁屏后也能用系统媒体控制；
- **整课离线**：一键下载整门课，进度可见、可暂停续传，装到手机桌面后没网也能听已下载的内容；
- **隐私优先**：音频只从家里局域网分发，不上传、不公开托管，页面带「仅供家庭私有使用」提示；
- **中英界面 + 浅色/深色/跟随系统三态**，在设置页一键切换且即时生效。

## 快速开始

需要 Node.js 22 和 pnpm。把听书音频放进 `兴趣测试/` 目录（层级：`等级/学科/课程目录/xxx.mp3`），然后：

```sh
pnpm install
pnpm audio:scan   # 扫描音频，生成目录索引 catalog/audio-index.json
pnpm build        # 构建前端与 PWA 资源
pnpm serve        # 启动服务，默认 http://127.0.0.1:8792/
```

电脑浏览器打开上面的地址就能用。端口被占用时换空闲端口：`APP_PORT=其他端口 pnpm serve`。

### 装到手机上

```sh
node scripts/android-preview.mjs
```

通过 USB 把页面安全地投给已授权的安卓手机（自动选空闲端口、不动其他服务），按终端输出的链接在手机 Chrome 打开，设置页点「安装小屋」即可加到桌面；之后下载过的课程断网也能听。

### 演示模式（不含真实数据）

```sh
node scripts/serve-demo.mjs   # http://127.0.0.1:8891，占位课程，仅用于查看界面
```

## 开发

```sh
pnpm dev          # 前端开发模式（API 指向 8792，可设 API_PROXY_TARGET）
pnpm test         # vitest 全量测试（单元 / 组件 / Node / 浏览器）
pnpm ts-check     # TypeScript 检查
pnpm lint         # ESLint
```

## 项目结构

- `src/audio/` — 听书应用主体（书库、课程、播放器、离线、引擎、中英文案）
- `audiobook-server.mjs` + `server/` — 本地服务：课程 API、音频 Range 流式分发、静态资源
- `scripts/` — 音频扫描、安卓 USB 预览、PWA 构建、演示实例
- `docs/qa/P51-运行与安装说明.md` — 运行与安装的完整边界说明
- `docs/qa/P51-最终交付与HumanGate.md` — 交付与验收记录

## 已知限制

- 课程清单、真实音频与扫描明细只保留在本机，不进入仓库（见 `.gitignore`）；新克隆需自备音频目录与课程清单后运行 `pnpm audio:scan`。
- 离线缓存存在手机浏览器里，清除网站数据或系统回收空间会删掉缓存（收听记录不丢）。
- 当前有 4 份损坏源文件，对应分集在界面上标为不可播放，不影响其余内容。
- 本项目从 P038「keep 运动健身仓库」复制应用基础结构起步；P038 的 Git 历史、运动数据与真实夹具均未复制，旧视频能力保留为 `src/LegacyVideoApp.tsx`，不作为默认入口。
